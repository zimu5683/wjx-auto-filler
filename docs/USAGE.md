# 使用说明（问卷自动填表 / wjx-auto-filler）

适用版本：**1.0.x**　|　适用系统：**Android 7.0（API 24）及以上**
（本文按钮名与 App 内文案一致；若后续界面调整，以 App 内实际显示为准。）

---

## 0. 一分钟上手

1. 打开 App → 顶部输入问卷链接，或点 **扫码** / **相册** 识别二维码
2. 点 **解析问卷** → 弹出「题目清单」
3. 在 **字段映射** 表里逐行填 **目标字段**（题号 / 题干关键词）与 **填充内容**
4. 需要多份答案就点 **新增组**（方案 1 / 方案 2 …），每组单独配置
5. 点 **并行提交** → 在 **提交结果** 区查看每组结果
6. 有新版本时点 **检查更新** 下载安装

---

## 1. 安装与首次启动

1. 从 [Releases](https://github.com/zimu5683/wjx-auto-filler/releases) 下载
   `wjx-autofill-<版本>-universal.apk`
2. 系统提示「未知来源」时，进入 **设置 → 应用 → 特殊权限 → 安装未知应用**，允许对应来源
   （该 APK 是**通用包**，内含 arm64-v8a / armeabi-v7a / x86 / x86_64 四个 ABI，任意 Android 7.0+ 设备直接安装）
3. 首次打开无需登录、无需注册

**权限说明**

| 权限 | 用途 | 拒绝后影响 |
| --- | --- | --- |
| 相机 `CAMERA` | **扫码** 实时识别问卷二维码 | 仍可用 **相册** 或直接粘贴链接 |
| 读取所选图片（系统照片选择器） | **相册** 导入二维码截图 | 仍可用扫码或粘贴链接 |
| 网络 `INTERNET` | 解析问卷、并行提交、检查更新 | 无法解析与提交 |
| 安装 APK（`REQUEST_INSTALL_PACKAGES`） | 应用内更新时唤起系统安装器 | 可手动到 Release 下载安装 |

App **不申请**存储写入、通讯录、定位、电话等权限。

## 2. 导入问卷

三种方式任选其一，链接会填入顶部「问卷链接」输入框：

1. **扫码**：进入扫码页「扫码识别问卷链接」，把二维码放入取景框；识别成功后自动返回并回填链接。
   扫码页提供 **手电筒：开/关** 开关；无可用后置相机时会提示改用相册。
2. **相册**：从系统照片选择器选二维码截图，本地解码后回填链接（图片不写入、不上传）。
3. **粘贴链接**：直接把链接粘进输入框。支持形式：
   - `https://www.wjx.cn/vm/Q0DQewW.aspx`
   - `https://www.wjx.cn/vm/Q0DQewW.aspx#`（带锚点）
   - `http://` 会被规范化为 `https://`

导入时会校验链接是否可用（域名 + 路径 + 可访问性）；不可用会提示「链接不可用：…」并不再继续。

## 3. 解析问卷

点 **解析问卷** → 拉取问卷页面，弹出 **题目清单**：

- 显示问卷标题与题目总数（「已解析：<标题>（共 N 题）」）
- 点选任一题目，会把该题的**标识**（题号，如 `1` / `q1`）自动填进字段映射表的**左栏**
- 点 **关闭** 收起题目清单

解析失败的提示与处理：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析失败：网络错误 / 超时 | 无网络或问卷星不可达 | 检查网络后重试 |
| 解析失败：问卷不存在或已停止 | 问卷被删除、关闭或链接错误 | 向问卷发布者确认链接 |
| 没有解析到题目 | 页面结构变化或返回了验证页 | 重试；若持续出现请提 issue 并附问卷链接 |

> 解析只读取公开问卷页面，不提交任何数据。

## 4. 字段映射（左右双栏）

「字段映射」是一张两列表格：

| 左栏：目标字段（题号 / 题干关键词） | 右栏：填充内容 |
| --- | --- |
| `1` 或 `q1` 或 `姓名` | 你要填的答案 |

- **新增一行**：加一条映射；**删除本行**：删掉该行
- **删除选中**：先勾选多行，再批量删除（未勾选会提示「请先勾选要删除的行」）
- **清空全部**：清空当前组的全部映射（会二次确认）
- 目标字段支持**题号**（`1`、`q1`）或**题干关键词**（如 `姓名`）；多选题、填空题都按该题标识匹配
- 提交后若某行没匹配到题目，结果区会提示「未匹配字段：…」；全部匹配则显示「全部字段已匹配」

> 提示：先用 **解析问卷** 打开题目清单、点选题目自动填左栏，比手写标识更稳。

## 5. 内容组（多份答案）

- **新增组**：默认命名「方案 1 / 方案 2 …」，每组有**独立的字段映射**
- **重命名**：自定义组名（如「方案 A」）
- **删除组**：删除该组及其全部映射（会二次确认）；**至少保留一个内容组**
- 顶部切换组标签即可编辑不同组；提交时**各组并行提交**，互不影响

> 建议并发组数控制在个位数并适当间隔，避免触发平台频率风控。

## 6. 模板：保存 / 导入 / 导出

- **保存模板**：填写模板名称后保存当前配置（问卷链接 + 各组字段映射），保存在本地
- **导入模板**：可粘贴模板 JSON 或点 **选择文件** 选文件，再点 **导入**；成功后提示「已导入 N 个内容组」
- **导出模板**：生成 JSON 并通过系统分享导出，便于备份或换机迁移

模板 JSON 的结构定义见 [docs/API-CONTRACT.md](API-CONTRACT.md)；请使用 App 导出的文件，
**不要手工编辑**（字段缺失会提示「模板解析失败：…」）。

## 7. 并行提交与查看结果

1. 确认问卷链接已填、每组至少有一条字段映射（否则会提示「请先填写或扫码获取问卷链接」/
   「请先配置至少一个字段映射」）
2. 点 **并行提交**：状态显示「正在并行提交 N 组…」，每组使用**独立会话**按问卷星表单协议提交
3. **提交结果** 区按组显示状态与结果，汇总显示「成功 N / 失败 M」
   - **等待中** / **成功** / **失败**
   - 未匹配字段会单独提示「未匹配字段：…」

结果含义：

| 结果 | 含义 |
| --- | --- |
| 成功 | 平台返回提交成功，答卷已记录 |
| 需要验证码 / 被风控拦截 | 该问卷启用了验证码或频率限制，**纯接口无法通过**，请改用问卷星官方页面人工填写 |
| 答卷已提交过 | 同一设备/会话被平台判定重复提交 |
| 网络错误 | 请求未完成，可重试 |

> 本工具**不会**尝试绕过验证码或风控；遇到拦截时请改用问卷星官方页面填写。

## 8. 检查更新

- 点 **检查更新**：匿名请求 GitHub Releases API 获取最新版本
  - 已最新：提示「已是最新版本 x.y.z」
  - 有新版：弹窗「发现新版本 x.y.z」+ 更新说明，可选 **下载并安装** / **以后再说** / **打开 Release 页面**
- 下载中显示进度百分比；下载完成后交系统安装器
- 若系统未允许安装未知应用，会提示先授权，返回后重新点击更新
- 该版本没有 APK 资产时会提示「该版本没有可下载的安装包，已打开 Release 页面」
- 检查失败提示「检查更新失败，请稍后再试」，不影响填表功能

安装时若提示「应用未安装 / 签名不一致」，说明当前安装包与 Release 包签名不同：
卸载后重装即可（**本地配置会丢失，请先导出模板**）。

## 9. 常见问题

**Q：扫码没反应？**
A：光线不足或二维码太小/模糊。可截图后用 **相册** 导入，或直接粘贴链接。

**Q：解析出来题目不全 / 点选题目没反应？**
A：问卷星页面结构可能已调整。请提交 issue，附问卷链接（公开问卷）与实际表现。

**Q：提交提示「未匹配字段」？**
A：左栏标识与问卷题目对不上。打开 **解析问卷** 的题目清单，点选题目自动填入标识。

**Q：提交总是失败？**
A：先看结果区的平台返回信息。若是验证码/风控，纯接口方案无法通过；若是网络错误，重试即可。

**Q：能用于别人的问卷吗？**
A：仅限已获得问卷所有者许可的场景。未经授权的批量提交可能违反平台条款与法律。

## 10. 数据与隐私

- 所有配置与模板都保存在设备本地的应用私有目录，App 不上传、不备份到任何服务器
- 唯一的外发请求是：问卷星页面/提交接口（你主动触发）与 GitHub 更新检查
- 卸载 App 即清除全部本地数据
