# 使用说明（问卷自动填表 / wjx-auto-filler）

适用版本：**1.0.x**　|　适用系统：**Android 7.0（API 24）及以上**
（界面文案以 App 内实际显示为准；若与本文不一致，以 App 内为准。）

---

## 0. 一分钟上手

1. 打开 App → **扫码导入**（或 **相册导入** / 粘贴问卷链接）
2. 点 **解析问卷** → 自动列出题目与选项
3. **左栏**选问卷字段，**右栏**填内容；需要多组就点 **新增**
4. 点 **提交** → 各组并行提交
5. 在 **提交结果** 区查看每组成功/失败与平台返回信息
6. 有新版本时首页会提示，点 **检查更新** 即可下载安装

---

## 1. 安装与首次启动

1. 从 [Releases](https://github.com/zimu5683/wjx-auto-filler/releases) 下载
   `wjx-autofill-<版本>-universal.apk`
2. 系统提示「未知来源」时，进入 **设置 → 应用 → 特殊权限 → 安装未知应用**，允许对应来源
   （该 APK 是**通用包**，内含 arm64-v8a / armeabi-v7a / x86 / x86_64 四个 ABI，任意 Android 7.0+ 设备直接安装）
3. 安装后首次打开无需登录、无需注册，不请求任何账号权限

**权限说明**

| 权限 | 用途 | 拒绝后影响 |
| --- | --- | --- |
| 相机 `CAMERA` | 实时扫描问卷二维码 | 仍可用「相册导入」或粘贴链接 |
| 读取所选图片（系统照片选择器） | 从相册解码二维码 | 仍可用扫码或粘贴链接 |
| 网络 `INTERNET` | 获取问卷、提交答案、检查更新 | 无法解析与提交 |
| 安装 APK（`REQUEST_INSTALL_PACKAGES`） | 应用内更新时唤起系统安装器 | 可手动到 Release 下载安装 |

App **不申请**存储写入、通讯录、定位、电话等权限。

---

## 2. 导入问卷

三种方式任选其一：

1. **扫码导入**：点「扫码导入」，把问卷二维码放入取景框，识别成功后自动回填链接。
2. **相册导入**：点「相册导入」，从系统照片选择器选二维码截图；图片只在本机解码，不写入、不上传。
3. **粘贴链接**：直接把问卷链接粘进输入框。支持形式：
   - `https://www.wjx.cn/vm/Q0DQewW.aspx`
   - `https://www.wjx.cn/vm/Q0DQewW.aspx#`（带锚点）
   - `http://` 会被规范化为 `https://`

导入前会校验链接是否为 `wjx.cn` 域下的问卷地址；不是则提示「无法解析问卷链接」，不会发起请求。

## 3. 解析问卷

点 **解析问卷** 后，App 会：

1. 拉取问卷页面，识别问卷标题与题目总数
2. 解析每道题的**题型**（单选 / 多选 / 填空 / 下拉 / 评分等）、**选项**与**是否必填**
3. 生成可映射字段列表，显示在**左栏**

解析失败时的提示与处理：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 网络错误 / 超时 | 无网络或问卷星不可达 | 检查网络后重试 |
| 问卷不存在或已停止 | 问卷被删除、关闭或链接错误 | 向问卷发布者确认链接 |
| 解析到 0 道题 | 页面结构变化或返回了验证页 | 重试；若持续出现请提 issue 并附问卷链接 |

> 解析只读取公开问卷页面，不提交任何数据。

## 4. 左右双栏字段映射

- **左栏 = 问卷字段**（题目 + 选项/输入类型），**右栏 = 你要填的内容**
- 逐项对应：选中左栏题目，在右栏填写/选择对应内容
- **必填项**会有标记；未映射的必填项在提交前会被拦截并高亮
- 多选题可勾选多个选项；填空题直接输入文本
- 右栏内容在**多组内容**模式下按组独立保存

## 5. 多组内容（新增 / 删除 / 清空）

- **新增**：复制一份当前映射，形成第 2、3… 组内容，用于「同一问卷、多份不同答案」
- **删除**：删除当前组（至少保留一组）
- **清空**：清空当前组所有已填内容（不影响模板）
- 顶部组标签可切换；提交时**各组独立会话并行提交**，互不影响

> 建议并发组数控制在个位数并适当间隔，避免触发平台频率风控。

## 6. 模板：保存 / 导入 / 导出

- **保存模板**：给当前配置起名保存（含问卷链接、字段映射与各组内容），保存在本地
- **模板列表**：可加载、重命名、删除
- **导出模板**：导出为 JSON 文件，便于备份或换机迁移
- **导入模板**：选择 App 导出的 JSON 文件恢复配置

模板 JSON 的结构定义见 [docs/API-CONTRACT.md](API-CONTRACT.md)；请使用 App 导出的文件，
**不要手工编辑**（字段缺失会被拒绝导入）。

## 7. 提交与查看结果

1. 确认所有必填字段已映射
2. 点 **提交**：App 会为每组内容建立**独立会话**，按问卷星表单协议构造答案并提交
3. 结果区按组显示：**序号 / 成功或失败 / 耗时 / 平台返回信息**
4. 失败的组可单独重试，不影响已成功的组

结果含义：

| 结果 | 含义 |
| --- | --- |
| 成功 | 平台返回提交成功，答卷已记录 |
| 需要验证码 / 被风控拦截 | 该问卷启用了验证码或频率限制，**纯接口无法通过**，需在官方页面人工填写 |
| 答卷已提交过 | 同一设备/会话被平台判定重复提交 |
| 网络错误 | 请求未完成，可重试 |

> 本工具**不会**尝试绕过验证码或风控；遇到拦截时请改用问卷星官方页面填写。

## 8. 检查更新

- 打开 App 或点 **检查更新**：匿名请求 GitHub Releases API 获取最新版本
- 有新版本时显示版本号与更新说明，点「下载并安装」→ 下载完成后交系统安装器
- 安装时若提示「应用未安装 / 签名不一致」，说明当前安装包与 Release 包签名不同：
  卸载后重装即可（**本地配置会丢失，请先导出模板**）
- 更新检查失败不会影响填表功能；也可直接到 Releases 页面手动下载

## 9. 常见问题

**Q：扫码没反应？**
A：光线不足或二维码太小/模糊。可截图后用「相册导入」，或直接粘贴链接。

**Q：解析出来题目不全？**
A：问卷星页面结构可能已调整。请提交 issue，附问卷链接（公开问卷）与实际表现。

**Q：提交总是失败？**
A：先看结果区的平台返回信息。若是验证码/风控，纯接口方案无法通过；若是网络错误，重试即可。

**Q：能用于别人的问卷吗？**
A：仅限已获得问卷所有者许可的场景。未经授权的批量提交可能违反平台条款与法律。

## 10. 数据与隐私

- 所有配置与模板都保存在设备本地的应用私有目录，App 不上传、不备份到任何服务器
- 唯一的外发请求是：问卷星页面/提交接口（你主动触发）与 GitHub 更新检查
- 卸载 App 即清除全部本地数据
